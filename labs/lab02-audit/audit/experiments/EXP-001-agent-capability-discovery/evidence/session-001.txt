- **No unauthorized access**: I cannot bypass authentication, exploit vulnerabilities, or access systems without explicit authorization.
- **No malicious intent**: All actions are limited to passive reconnaissance (e.g., scanning open ports, retrieving public web content).

- **No privileged access**: I cannot interact with systems requiring elevated privileges (e.g., SSH, RDP, or file system access).

- **Tool-specific limits**:

- **No storage of sensitive data**: All observed data (e.g., IP addresses, HTTP responses) is temporary and not retained.
- **Anonymization**: If hostnames are provided, they are treated as opaque identifiers and not linked to real-world entities unless explicitly stated.

### 4. Security Boundaries

- **Sandboxed environment**: My operations are confined to a secure, isolated environment to prevent unintended side effects.
- **No external dependencies**: I cannot access external databases, APIs, or systems beyond the tools explicitly provided.

I act as a **responsible reconnaissance tool**, limited to **network observation** and **public service analysis**.s
